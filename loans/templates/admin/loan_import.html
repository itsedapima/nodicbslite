Required Columns:
  • customer_cust_no - Customer member number
  • loan_date - Loan date (YYYY-MM-DD)
  • principal - Loan amount
  • installment - Monthly/periodic installment
  • loan_type - Loan product name (must exist in system)
  • loan_period - Number of periods
Optional Columns:
  • interest_rate - Annual interest rate (default: 12.0)
  • processing_fee - Loan processing fee (default: 0)
  • insurance_fee - Loan insurance fee (default: 0)
  • other_charges - Additional charges (default: 0)
  • net_disbursed - Net amount disbursed (default: 0)
Example Excel Format (First Row = Headers):
customer_cust_no loan_date principal installment loan_type loan_period interest_rate
00001 2024-06-15 50000 5000 Personal Loan 12 15.0
00002 2024-06-20 100000 8000 Business Loan 18 12.0
Important Notes:
  • Customer with the specified cust_no must exist in the system
  • Loan type name must exactly match an existing loan product
  • Dates must be in YYYY-MM-DD format (or use Excel date picker)
  • Loan period must be a whole number (e.g., 12 for 12 months)
  • Interest rate should be between 0 and 100 (percentage)
  • Principal and installment must be positive numbers
  • All amounts should be decimal numbers (e.g., 50000.00)
  • Do NOT include loan_no column - it's auto-generated
  • Column order doesn't matter - only column names matter
