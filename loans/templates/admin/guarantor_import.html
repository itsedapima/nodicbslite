Required Columns:
  • loan_no - Loan number (e.g., LN000001, MOBI00001)
  • guarantor_cust_no - Guarantor's member number
  • amount - Amount guaranteed (must be ≤ loan principal)
Example Excel Format:
loan_no guarantor_cust_no amount
LN000001 00002 25000
LN000001 00003 25000
LN000002 00001 50000
Important Notes:
  • Loan must exist (by loan_no) in the system
  • Guarantor customer must exist (by cust_no)
  • Guarantee amount must be positive and ≤ loan principal
  • Guarantor cannot be the loan borrower
  • One loan can have multiple guarantors (multiple rows)
  • Column order doesn't matter - only column names matter
